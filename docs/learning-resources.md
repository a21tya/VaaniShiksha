# Learning Hub catalog

The Learning Hub links to NCERT's own textbook reader; it does not redistribute or claim to store PDFs offline. Bookmarks store resource IDs on the user's device. The 31 entries cover the NCERT subject areas for Classes 1–5, with Hindi and English mathematics options for Classes 1–2. Other language editions remain accessible from the linked official catalog. Cards use original typographic illustrations, not reproductions of official covers.

Catalog sources reviewed on 8 September 2026:

- NCERT textbook portal: https://ncert.nic.in/textbook.php
- NCERT school advisory, including foundational book titles: https://ncert.nic.in/pdf/announcement/NCERT-Advisory-for-Schools.pdf
- NCERT publication list: https://ncertbooks.ncert.gov.in/static/Latest%20rate%202025.xlsx.pdf
- CBSE circular with all seven Class 5 book destinations: https://www.cbseacademic.nic.in/web_material/Circulars/2025/48_Circular_2025.pdf
- Class 1–2 link list from KV NTPC Kayamkulam Library: https://kvkymlib1.wordpress.com/2023/07/
- Class 3 link list from PM SHRI KV AFS Bamrauli Library: https://pmshrikvblib.wordpress.com/2024/08/14/class-iii-books/
- Class 4 published link list: https://knowscope.in/wp-content/uploads/2025/04/NCERT-BRIDGE-COURSE-FOR-IV.pdf
- Class 4 NCERT bibliographic record: https://webopac.ncert.gov.in/bib/195314
- NCERT Class 2 mathematics indexed reader: https://ncert.nic.in/textbook.php?bejm1=2-11
- Urdu link references: https://www.researchgate.net/publication/393163473_Musical_Names_of_NCERT_Books_and_its_Socio-Cultural_Analysis

NCERT's live portal timed out/reset connections in this environment during implementation. Indexed official listings and published link lists were used; this is not a claim that every external endpoint was live-tested. Keep explicit book IDs in `lib/learning-resources.ts` and check against NCERT when revising editions. Classes 1–2 do not get fabricated standalone EVS, arts, or PE textbook entries.

The dictionary is an original, locally bundled Hindi–English starter collection with 36 common words, simple definitions, transliterations, and examples. It is not an NCERT dictionary or a full translation service. Unverified Santhali entries have not been relabeled as verified dictionary entries. Add reviewed words through the typed data collection as it grows.
